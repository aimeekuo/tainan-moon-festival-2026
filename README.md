## ✨ 核心特色與功能

1. **📱 手機體驗最佳化 (Mobile-First)**
   - 模擬原生 App 體驗，配備底部導航欄（行程、速查、行李、記帳）。
   - 支援 iOS / Android「加到主畫面」全螢幕瀏覽 (PWA Ready)。
   - 支援中秋出發倒數計時與每日天氣卡片。

2. **📅 每日時間軸行程表 (Interactive Timeline)**
   - 橫向滑動 Day 1 ~ Day 4 標籤。
   - 景點卡片標籤分類（景點、美食、咖啡、購物、住宿、交通、活動）。
   - **一鍵 Google Maps 導航**：點擊「導航」直接在手機開啟 Google 地圖規劃路線。
   - **打卡標記「已抵達」**：點擊後噴出慶祝彩帶並記錄進度。
   - **交通與兩路會合提示**：清晰標記高鐵車次、開車路線與下一站預估時間。

3. **ℹ️ 家人實用速查手冊 (Quick Info Hub)**
   - **同行人員分工**：明確記錄台北高鐵組與北斗自駕組名單。
   - **下榻飯店憑證**：致穩人文商旅 (Agoda 1766846905，9/25 七人全住) 與台南維悅酒店 (Klook RBJ197934 家庭房 / SJB056326 雙人房) 地址一鍵複製、導航、一鍵撥打總機；並標記需補訂房間與確認加床的提醒。
   - **高鐵車票憑證**：去程 1309 車次、回程 1326 車次取票代碼與車廂座位。
   - **緊急與重要專線**：飯店總機、高鐵客服、緊急報警/救護專線一鍵直撥。

4. **🧳 行李與裝備清單 (Packing Checklist)**
   - 分門別類：出發前要辦的事（補訂房、確認加床、餐廳訂位）、重要證件與票券、電子通訊設備、常備藥品與防蚊防曬、衣物與中秋伴手禮（含小朋友安安、睿睿隨身用品）。
   - 互動打勾與進度條，全部備齊時觸發彩帶祝賀！

5. **💰 公費記帳與自動分攤 (Family Expense Ledger)**
   - 記錄公費花費（項目、金額、誰代墊、分類）。
   - 支援記錄 Aimee、ㄚ維 等家人代墊，自動計算每人平均分攤金額與代墊結算。

6. **🔗 家人一鍵分享與備份 (Sharing & Backup)**
   - **QR Code 掃碼分享**：家人直接用手機相機掃碼即可打開相同行程。
   - **網址參數分享**：支援將行程整包壓縮編碼於網址中發送至 LINE 家庭群組。
   - **本機自動儲存 (LocalStorage)**：離線狀態或網路斷線也能隨時查看。
   - **JSON 匯入/匯出**：可將行程匯出檔案備份或傳給家人匯入。

## 🚀 快速啟動與手機瀏覽

### 方法一：使用內建 Python 伺服器在手機上預覽
在終端機中執行：
```bash
cd "/Users/aimeekuo/Desktop/travel plan"
python3 serve.py
```
伺服器會顯示本機 IP，例如：
```
http://192.168.1.100:8080
```
只要您的手機與電腦連接在同一個 Wi-Fi 網路，手機打開 Safari 或 Chrome 輸入該網址即可立刻瀏覽與操作！

### 方法二：直接瀏覽 HTML 檔
用任何瀏覽器雙擊打開 `index.html` 即可完整使用所有功能。

### 方法三：免費線上部署（分享給任何網路下的家人）
將此資料夾檔案上傳至：
- **GitHub Pages** (免費靜態託管)
- **Vercel** / **Netlify** / **Cloudflare Pages** (拖拉資料夾 30 秒上線)
產生永久網址後，傳在 LINE 家庭群組中即可隨時查看！
